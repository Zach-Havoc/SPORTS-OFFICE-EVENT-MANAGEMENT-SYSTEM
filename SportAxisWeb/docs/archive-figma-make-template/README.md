# Archived — Figma Make template docs (Supabase era)

This project started from a Figma Make-generated starter template backed by
Supabase. It has since been fully rebuilt on a real Laravel 13 backend — see
the actual current architecture in the repo root `README.md` and
`INFINITYFREE_DEPLOYMENT.md` instead.

Everything in this folder describes that original Supabase-based scaffold
(confirmed: every file here references Supabase, none of which this system
uses anymore) and is kept only for historical reference — **do not follow
these as setup/install instructions**, they describe a different backend
than what's actually running today.
